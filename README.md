# 编程练习（C / Python）

大一（2026 秋）编程练习的版本库。C 跟课内《计算机程序设计》，Python 走自学线。

## 文件对应

| 文件 | 内容 |
|---|---|
| `c1.c` | 第一个 C 程序（打印） |
| `c2.c` | 变量与数据类型 |
| `c3.c` | 输入输出与运算 |
| `c4.c` | 类型大小与 `sizeof` |
| `c6.c` | 一周气温统计（数组：极值/平均/逆序/最长连续升温） |
| `c7.c` | 十进制浮点数转二进制（整数部分除 2 取余、小数部分乘 2 取整） |
| `c8.c` | 二维数组找鞍点（行最大 + 列最小） |
| `Demo1.py`–`Demo3.py` | Python 入门练习（含 GPA 计算器） |
| `C语言每日一题.md` | 每日练习的进度、出题队列和答题记录 |

> 说明：`.exe` 是编译产物，已在 `.gitignore` 里排除，不进仓库。

## 编译方式

```bash
gcc -Wall c6.c -o c6.exe
```

统一加 `-Wall`，警告当错误看。
